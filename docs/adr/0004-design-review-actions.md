# ADR-0004: 設計レビュー指摘と対応方針

- **ステータス**: 承認済み（対応完了）
- **日付**: 2026-02-08

## コンテキスト

Broth の設計ドキュメント全体に対する外部レビューを実施し、20 項目の指摘を受けた。各指摘を評価し、対応要否を判断した。

## 対応が必要と判断した項目（9 件）

### 1. JWT ライブラリの採用（最優先）
- **指摘**: JWT の自前実装はセキュリティリスク
- **対応**: `golang-jwt/jwt` v5 を採用。セキュリティライブラリは P1 の最小依存原則の例外として許容（ADR-SEC006 改訂）

### 2. `broth generate query` の方針変更
- **指摘**: SQL パーサの自前実装は困難
- **対応**: Phase 1 では sqlc ラッパーとして実装（後に Bob 採用で解消）

### 3. Buffalo/Beego 失敗分析の文書化
- **指摘**: 競合分析が薄い
- **対応**: 競合分析を実施し ADR-0003 として文書化

### 4. テスト戦略の文書化
- **指摘**: テスト方針が明示されていない
- **対応**: 各レイヤーのテスト方針を CLAUDE.md およびREADME に追記

### 5. PostgreSQL 固有機能の明記
- **指摘**: CONCURRENCY_DESIGN の PostgreSQL 依存が不明確
- **対応**: `FOR UPDATE SKIP LOCKED`、Advisory Lock 等の PostgreSQL 固有機能を明記

### 6. OSS 公開基盤の整備
- **指摘**: LICENSE、CONTRIBUTING、バージョニング方針が未整備
- **対応**: MIT License 追加、CONTRIBUTING.md 作成、SemVer + Go Modules 方針策定

### 7. 英語ドキュメント
- **指摘**: 国際コミュニティ参加のため英語化が必要
- **対応**: Phase 2 以降で対応予定

## 対応不要と判断した項目（11 件）

以下は、既に設計書で対応済みか、現フェーズでは時期尚早と判断した：

- マイグレーションガイド（Phase 1 では不要）
- プラグインシステム（YAGNI: P4）
- SSR 専用という誤読（SSR/API 自動判定は実装済み）
- 市場規模の懸念（ニッチ戦略は意図的）
- その他 5 件（設計書の既存記述で対応済み）

## 決定

9 件の対応項目を優先度順に実施。本 ADR は対応の追跡記録として保持する。
